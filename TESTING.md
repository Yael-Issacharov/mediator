# Stage 6 test checklist

Run these in the **Claude app** on https://claude.ai/artifact/NC9LEiCvLAPsEz5hQkgVNW.
Live AI only works there. Each step names the spec §21 acceptance criterion it covers.

## A. One click: all four scenarios (about 3 minutes)
1. Go to **Settings → Testing → Open scenario tests**, then press **Run all four scenarios**.
2. When it finishes, press **Copy results** and paste the text into the chat.

What passes:
- Scenario 3 (Two Strong Opinions) shows **Genuine disagreement** and no "Invented gap" chip.
- Every quote count is full, for example 6/6.
- Each report is under about 400 words.

Covers criteria 7, 12–16.

## B. By hand (about 10 minutes)
| # | Do this | Expect | Covers |
|---|---|---|---|
| 1 | Open **Home** | The concept, the 4-step flow, the scenarios and the participants are clear without explanation | 1–2 |
| 2 | **Participants**: open Maya, then the **Assessment** tab. Change 2 answers and save | The profile becomes v2, and a list shows which statements were added (+) and removed (−) | 3–5 |
| 3 | **Compare profiles** | The Similar/Different rows reflect your change. No score anywhere | 6 |
| 4 | **Conversations → Paste transcript**: write 4–6 lines as `Name: text`, then Review | The speakers are detected. Assign them to A and B, and add a topic in Optional context | 8, 10–11 |
| 5 | **Upload file**: `mediator/samples/handoff-conversation.docx` | 6 turns, with speakers Noa and Tal | 9 |
| 6 | Run the analysis on your pasted conversation | The report has Key points, the 6 sections, quotes that highlight in the transcript, and Observation / Hypothesis / Unknown rows | 12–16 |
| 7 | On one finding, press **Approve**, **Correct** (type a correction) and **Reject** in turn | The state chip changes each time, and a rejected finding is struck through and collapsed | 17 |
| 8 | Edit the conversation or a profile, then go back to that report | The "earlier version" banner appears, and **Rerun analysis** produces a new run listed under "Runs" | 18 |
| 9 | **Settings → Simulate an AI failure** on, then Run on any scenario | An error with **Retry** and **Show demo example**. The demo shows the exact label "Demo Example — Not Generated by Live AI". **Turn the toggle off afterwards.** | 19 |

## Report back
Paste the results text from A, plus any row in B that did not behave as expected.
